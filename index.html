ScopeWeaver Mail

The email connector for the ScopeWeaver security-testing platform. It lets an operator's own automated agents read, search, label, and organize messages inside email accounts that the operator personally controls — so that engagement notifications, bug-bounty correspondence, and report threads can be triaged automatically during authorized security work.

What it does

  • Read and search

    Search threads with Gmail search syntax and read message bodies and headers.

  • Organize

    Apply and remove labels, archive, mark as read, and manage drafts.

  • Single-tenant

    Self-hosted. Each connector instance is bound to one mailbox the operator owns.

Who uses it

ScopeWeaver Mail is operated by the account owner. It is not a consumer product, it has no public sign-up, and it does not create accounts for third parties. Access is granted only through Google's standard OAuth consent flow, initiated by the mailbox owner.

Google API disclosure

ScopeWeaver Mail's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Data handling at a glance

Message data is processed only to provide the features listed above, on infrastructure controlled by the operator. It is never sold, never used for advertising, and never used to train generalized AI/ML models. See the Privacy Policy for the full description.
